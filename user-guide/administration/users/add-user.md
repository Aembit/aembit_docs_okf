# How to add a user

To add a user to your Aembit Tenant, perform the following steps:

1. Log into your Aembit Tenant.

2. Click **Administration** in the left sidebar.

3. At the top, select **Administration ☰ Users**.

   Aembit displays the **Users** page with a list of existing users.

   ![Empty Users page](https://docs.aembit.io/_astro/administration_users_main_page_empty.BbOUkB0u_Z221FtX.webp)

4. Click **+ New**, revealing the **Users** pop out menu.

5. Fill out the following fields:

   * **First Name** - First name of the user **Last Name** - Last name of the user
   * **Email** - The email address associated with the user
   * **Country Code (optional)** - The country code associated with the user
   * **Phone Number (optional)** - The phone number associated with the user.
   * **Role Assignments** - Select the specific role assignments for the user from a list of available roles.

   ![Completed Users pop out menu](https://docs.aembit.io/_astro/administration_users_dialog_window_completed.D0QPPxoo_1kqz96.webp)

6. Click **Save**.

   Aembit displays the new user on the **Users** page.

   ![Users Page - New User Added](https://docs.aembit.io/_astro/administration_users_main_page_with_new_user.CpvyrIWY_Zuzxop.webp)
