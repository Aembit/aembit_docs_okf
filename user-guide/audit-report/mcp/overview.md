# MCP reports

The Reporting dashboard includes the following views for MCP traffic through the MCP Identity Gateway:

| View                                                                             | Use it to                                                                                                |
| -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| [MCP Access Activities](access-activities.md)         | Review MCP requests with no error or exception code, by user, MCP client, MCP server, method, and target |
| [MCP Access Exceptions](access-exceptions.md)         | Review MCP requests that have an error or an exception code                                              |
| [MCP Authorization Tracing](authorization-tracing.md) | Watch MCP authorization requests live                                                                    |

To read every field of the Workload Events behind MCP Access Activities and MCP Access Exceptions, see [Workload Events](../workload-events/overview.md).
