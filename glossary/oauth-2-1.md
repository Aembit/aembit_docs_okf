# OAuth 2.1

An updated consolidation of the OAuth 2.0 specification that mandates PKCE for all clients, removes the implicit grant and resource owner password grant, and requires stricter security defaults.

Learn more: [OAuth 2.1](https://oauth.net/2.1/)
