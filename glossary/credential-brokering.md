# Credential brokering

The process of mediating credential issuance between a requesting workload and a target resource. The broker verifies identity, evaluates policy, and issues short-lived credentials so that workloads never manage static secrets directly.

Learn more: [Credential brokering](../get-started/how-aembit-works.md)
