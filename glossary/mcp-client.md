# MCP Client

An application (such as Claude Desktop, Claude Code, or Gemini CLI) that connects to MCP servers to access tools and resources on behalf of users.

Learn more: [MCP Client](https://docs.aembit.io/user-guide/ai/mcp-auth-server/setup-mcp-auth-server/)
