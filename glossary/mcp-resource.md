# MCP Resource

Data that an MCP server exposes for context, such as files, database schemas, or documentation. Unlike tools, which are model-controlled, resources are application-controlled — the client or user decides when to retrieve them, not the model.

Learn more: [MCP Resource](https://modelcontextprotocol.io/specification/2025-03-26/server/resources)
