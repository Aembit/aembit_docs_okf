# OpenID Connect (OIDC)

An identity layer built on top of OAuth 2.0 that lets applications verify the identity of a user or workload and obtain basic profile information using JSON Web Tokens (JWTs).

Learn more: [OpenID Connect (OIDC)](https://openid.net/developers/how-connect-works/)
