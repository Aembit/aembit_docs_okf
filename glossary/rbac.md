# RBAC (Role-Based Access Control)

A security model that restricts system access based on user roles. In Aembit, RBAC controls which administrators can perform specific actions like creating policies, viewing audit logs, or managing credentials.

Learn more: [RBAC (Role-Based Access Control)](../user-guide/administration/roles/overview.md)
