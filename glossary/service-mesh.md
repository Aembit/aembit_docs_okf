# Service mesh

A dedicated infrastructure layer that manages service-to-service communication in a microservices architecture, typically through sidecar proxies. Handles concerns like load balancing, encryption, authentication, and observability.

Learn more: [Service mesh](https://glossary.cncf.io/service-mesh/)
