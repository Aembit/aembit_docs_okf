# vCenter

VMware vCenter Server is a centralized management platform for VMware vSphere environments that provides VM lifecycle management, monitoring, and APIs for querying VM metadata such as UUIDs and MAC addresses.

Learn more: [vCenter](https://docs.vmware.com/en/VMware-vSphere/index.html)
