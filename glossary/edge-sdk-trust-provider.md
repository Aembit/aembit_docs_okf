# Trust Provider (Edge SDK)

The object your program passes to the Edge SDK client to collect identity evidence from the environment it runs in, such as an OIDC token or an instance identity document. The SDK presents that evidence to Aembit, where the Trust Provider you configured in your Aembit Tenant verifies it.

Learn more: [Trust Provider (Edge SDK)](../dev-guide/sdk/edge/overview.md)
