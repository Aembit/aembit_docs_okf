# Embedded user authorization

An MCP authorization flow in which your application signs a user in through an OIDC Identity Provider and authorizes their access to one MCP server, with no Aembit page in the browser. The MCP Identity Gateway then uses that access on the user's behalf.

Learn more: [Embedded user authorization](../user-guide/access-policies/mcp-identity-gateway/embedded-user-authorization.md)
