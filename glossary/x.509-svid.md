# X.509-SVID

A SPIFFE Verifiable Identity Document in X.509 certificate format. X.509-SVIDs are certificates that embed a workload's SPIFFE ID as a URI Subject Alternative Name (SAN) and enable mutual TLS authentication between workloads. Aembit issues SVIDS with short lifetimes and automatic rotation.

Learn more: [X.509-SVID](../user-guide/access-policies/credential-providers/about-spiffe-x509-svid.md)
