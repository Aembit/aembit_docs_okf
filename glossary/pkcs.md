# PKCS

Public Key Cryptography Standards (PKCS) are a family of standards for cryptographic operations. PKCS#8 defines a format for private keys, while PKCS#1 specifically defines RSA key formats. Network Identity Attestor requires PKCS#8 format for signing keys.

Learn more: [PKCS](https://en.wikipedia.org/wiki/PKCS)
