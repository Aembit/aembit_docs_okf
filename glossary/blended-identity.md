# Blended Identity

An access model that combines a human user's identity (authenticated through an Identity Provider) with an AI agent's workload identity into a single access decision, enabling policies that evaluate both "who is this user" and "which agent are they using" simultaneously.

Learn more: [Blended Identity](../user-guide/access-policies/blended-identity.md)
