# Single Sign-On (SSO)

An authentication scheme that lets users sign in once through a central identity provider, such as Okta, and then reach several applications without signing in to each one separately.

Learn more: [Single Sign-On (SSO)](../user-guide/administration/identity-providers/overview.md)
