# Enterprise-Managed Authorization

An MCP authorization flow in which the corporate identity provider decides which users and AI agents can reach an MCP server, and a trusted party exchanges the user's single sign-on identity for an MCP server access token without a per-user consent prompt.

Learn more: [Enterprise-Managed Authorization](../user-guide/access-policies/credential-providers/about-mcp-enterprise-managed-access-token.md)
