# Gateway-to-Server Policy

The Access Policy that authorizes the MCP Identity Gateway to access an MCP server on behalf of authenticated users—the Gateway itself is the Client Workload. Also called right-side auth; each MCP server behind the Gateway needs its own.

Learn more: [Gateway-to-Server Policy](../ai-guide/mcp/identity-gateway/concepts-mcp-gateway.md#identity-aware-access-policies)
