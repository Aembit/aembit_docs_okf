# Process Hash Attestation

Process Hash Attestation is an Aembit feature that calculates the SHA-256 hash of a workload's executable binary at runtime and embeds it in token claims, enabling zero-trust verification that only approved binaries can access protected resources.

Learn more: [Process Hash Attestation](https://docs.aembit.io/user-guide/deploy-install/virtual-envs/process-hash-attestation)
