# Network Identity Attestation

Network Identity Attestation (NIA) is an Aembit feature that provides cryptographically verifiable identity for workloads in virtualized environments by issuing signed attestation documents based on VM metadata from the hypervisor.

Learn more: [Network Identity Attestation](https://docs.aembit.io/user-guide/deploy-install/virtual-envs/about-network-identity-attestation)
