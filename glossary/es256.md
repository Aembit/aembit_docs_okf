# ES256

An elliptic curve digital signature algorithm (ECDSA with P-256 and SHA-256) used by Aembit for signing access tokens. ES256 provides strong security with compact key sizes.

Learn more: [ES256](../ai-guide/mcp/authorization-server/reference-mcp-auth-server.md#token-algorithm)
