# MCP App

A UI application that renders inside an MCP host such as Claude Desktop. MCP Apps combine a tool (which declares a UI resource via _meta.ui.resourceUri) with an HTML resource that the host renders in a sandboxed iframe. Defined as an extension to the core MCP specification.

Learn more: [MCP App](../user-guide/deploy-install/about-mcp-servers-and-apps.md)
