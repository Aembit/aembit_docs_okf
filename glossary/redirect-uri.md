# Redirect URI

The callback URL where the Authorization Server redirects users after authentication. For MCP clients, the redirect URI serves as a Client Workload identifier in Aembit Access Policies.

Learn more: [Redirect URI](../user-guide/access-policies/mcp-authorization-server/setup-mcp-auth-server.md)
