# PKCE (Proof Key for Code Exchange)

An OAuth 2.0 extension that prevents authorization code interception attacks. The client creates a cryptographic challenge during the authorization request and proves possession of the original secret when exchanging the code for a token.

Learn more: [PKCE (Proof Key for Code Exchange)](https://oauth.net/2/pkce/)
