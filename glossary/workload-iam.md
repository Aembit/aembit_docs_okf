# Workload IAM

Identity and Access Management for non-human entities (services, applications, automated workloads) rather than human users. Unlike traditional IAM that manages user access, Workload IAM manages machine-to-machine authentication and authorization.

Learn more: [Workload IAM](../get-started/how-aembit-works.md)
