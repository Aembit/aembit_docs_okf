# Dynamic Client Registration

An OAuth mechanism that allows MCP clients to register with the Authorization Server at runtime without pre-configuration, receiving unique credentials for subsequent authorization requests.

Learn more: [Dynamic Client Registration](../ai-guide/mcp/authorization-server/concepts-mcp-auth-server.md#client-registration)
