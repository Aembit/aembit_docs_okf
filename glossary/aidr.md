# AIDR

CrowdStrike AI Detection and Response (AIDR) is a content inspection service that scans MCP tool listings, tool call inputs, and tool call outputs in real time and returns an allow, block, or transform verdict to Aembit.

Learn more: [AIDR](../user-guide/access-policies/content-security/crowdstrike-aidr/overview.md)
