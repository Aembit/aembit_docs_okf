# JWT-SVID

A SPIFFE Verifiable Identity Document in JWT format. JWT-SVIDs are cryptographically signed, short-lived tokens that prove workload identity and enable secure authentication without static credentials.

Learn more: [JWT-SVID](../user-guide/access-policies/credential-providers/about-spiffe-jwt-svid.md)
