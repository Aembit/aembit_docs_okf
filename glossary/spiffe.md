# SPIFFE

Secure Production Identity Framework For Everyone (SPIFFE) is an open standard for workload identity that provides cryptographically verifiable identities to services without relying on shared secrets.

Learn more: [SPIFFE](https://spiffe.io/docs/latest/spiffe-about/overview/)
