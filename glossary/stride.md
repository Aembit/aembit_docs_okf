# STRIDE

STRIDE is a threat modeling framework developed by Microsoft that categorizes security threats into six types - Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, and Elevation of Privilege. It provides a systematic approach to identifying potential security vulnerabilities.

Learn more: [STRIDE](https://learn.microsoft.com/en-us/azure/security/develop/threat-modeling-tool-threats)
