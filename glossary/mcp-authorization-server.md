# MCP Authorization Server

The Aembit component that provides OAuth 2.1 authorization for Model Context Protocol (MCP) servers, enabling secure access control for AI agents and MCP clients.

Learn more: [MCP Authorization Server](https://docs.aembit.io/user-guide/ai/mcp-auth-server/about-mcp-auth-server/)
