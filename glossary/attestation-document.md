# Attestation Document

An attestation document is a cryptographically signed JSON document containing workload metadata (such as VM name, UUID, and MAC address) that proves a workload's identity. Aembit Cloud verifies the signature to authenticate the workload.

Learn more: [Attestation Document](https://docs.aembit.io/user-guide/deploy-install/virtual-envs/about-network-identity-attestation)
