# Tool annotations

Metadata in MCP tool discovery responses that categorize tools by behavior, such as read-only or destructive operations. MCP clients use annotations to drive safety decisions — specifically whether to auto-approve a tool call or prompt the user for confirmation.

Learn more: [Tool annotations](https://modelcontextprotocol.io/specification/2025-03-26/server/tools#annotations)
