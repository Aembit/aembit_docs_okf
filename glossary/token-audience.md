# Token Audience

The intended recipient of an access token, specified in the aud claim. For MCP servers, the audience is typically the server's public URL and must match exactly between token issuance and validation.

Learn more: [Token Audience](../ai-guide/mcp/authorization-server/concepts-mcp-auth-server.md#token-audience)
