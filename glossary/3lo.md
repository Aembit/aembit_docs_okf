# 3LO

3-legged OAuth (3LO) is the OAuth 2.0 Authorization Code flow where a user explicitly authorizes an application to access their data on a third-party service, requiring user interaction to complete the authorization.

Learn more: [3LO](../user-guide/access-policies/credential-providers/oauth-authorization-code.md)
