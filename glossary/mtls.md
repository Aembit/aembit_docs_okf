# mTLS

Mutual Transport Layer Security. A TLS handshake in which both the client and server present certificates and validate each other's identity before any application traffic flows. mTLS is commonly used for workload-to-workload authentication where both parties must prove identity at the transport layer.

Learn more: [mTLS](../user-guide/access-policies/server-workloads/enable-mtls.md)
