# Credential Provider

Credential Providers obtain the specific access credentials—such as API keys, OAuth tokens, or temporary cloud credentials—that Client Workloads need to authenticate to Server Workloads.

Learn more: [Credential Provider](../get-started/concepts/credential-providers.md)
