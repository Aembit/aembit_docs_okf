# MAC Address

A Media Access Control (MAC) address is a unique hardware identifier assigned to a network interface card (NIC). In virtualized environments, the hypervisor assigns virtual MAC addresses to VMs, which Network Identity Attestor uses to verify VM identity.

Learn more: [MAC Address](https://en.wikipedia.org/wiki/MAC_address)
