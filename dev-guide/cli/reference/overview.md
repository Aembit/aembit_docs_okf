# aembit

Use the Aembit CLI to work with your Aembit-managed credentials.

## Commands

* [`aembit`](aembit.md) - base command for the Aembit CLI
* [`aembit credentials get`](credentials-get.md) - retrieve credentials for a specific Client Workload
