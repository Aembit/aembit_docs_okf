# CredentialProviderTypes

Type of credential being requested from your configured Credential Provider.
Note: Use 'OAuthToken' for Azure Entra ID, Microsoft, and generic OAuth2 providers.

**Type:** string

**Possible values:** `Unknown`, `ApiKey`, `UsernamePassword`, `GoogleWorkloadIdentityFederation`, `OAuthToken`, `AwsStsFederation`, `X509Svid`
