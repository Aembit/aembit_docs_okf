# AuthorizationEventClientRegistrationDTO

Client registration details for an Access Authorization Event

**Type:** object

**Properties:**

- **clientId** *(optional)*: null,string - The client identifier
- **clientName** *(optional)*: null,string - The human-readable client name
- **redirectUris** *(optional)*: null,array - Registered redirect URIs
- **grantTypes** *(optional)*: null,array - Allowed OAuth2 grant types
- **responseTypes** *(optional)*: null,array - Allowed OAuth2 response types
