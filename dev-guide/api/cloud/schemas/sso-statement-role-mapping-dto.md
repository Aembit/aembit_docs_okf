# SsoStatementRoleMappingDTO

Represents a mapping of an SSO attribute to an Aembit role

**Type:** object

**Properties:**

- **attributeName** *(optional)*: null,string - SSO Attribute name
- **attributeValue** *(optional)*: null,string - SSO Attribute value
- **roleExternalId** *(optional)*: string (uuid) - Aembit Role ID
