# UserAgentDTO

DTO for the HTTP User Agent of an individual Aembit Audit Log

**Type:** object

**Properties:**

- **browser** *(optional)*: null,string - The browser as determined from the HTTP User Agent
- **operatingSystem** *(optional)*: null,string - The operating system as determined from the HTTP User Agent
- **raw** *(optional)*: null,string - The raw HTTP User Agent
