# McpAccessDecisionDTO

Access policy decision for an MCP boundary

**Type:** object

**Properties:**

- **boundary** *(optional)*: null,string - The boundary name
- **policyName** *(optional)*: null,string - The evaluated access policy name
- **decision** *(optional)*: null,string - The access decision (e.g., Authorized, Denied, Unavailable)
